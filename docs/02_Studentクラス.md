## 1. Studentクラスの役割

Studentクラスは、学生1人分の情報を管理するためのクラスです。

今回の学生成績管理アプリでは、次の情報を管理します。

- 学生の名前
- 数学の点数
- 英語の点数
- 国語の点数
- 3教科の平均点

また、平均点を計算する処理もStudentクラスの中に用意しています。

つまり、Studentクラスは「学生のデータ」と「学生に関係する処理」をまとめたものです。

## 7. なぜ `3` ではなく `3.0` を使うの？

これはC#の計算で重要なポイントです。

C#では、整数同士の割り算をすると、小数部分が切り捨てられます。

例えば、次のコードです。

```csharp

Console.WriteLine(5 / 2);

```

結果は次のようになります。

```text

2

```

一方、次のコードでは、

```csharp

Console.WriteLine(5 / 2.0);

```

結果は次のようになります。

```text

2.5

```

`2.0` は小数を扱う数値なので、計算結果も小数を含む値になります。

今回の平均点の計算でも、小数部分を残したいため、`3.0` を使用しています。


`2.0` は小数を扱う数値なので、計算結果も小数を含む値になります。

今回の平均点の計算でも、小数部分を残したいため、`3.0` を使用しています。

## 10. なぜStudentクラスを作成したのか？

学生の名前や各教科の点数を、個別の変数だけで管理するのではなく、1人分の情報としてまとめて扱うためです。

Studentクラスを用意することで、学生が増えた場合にも、同じ設計を使って学生情報を作成できます。

また、平均点の計算処理もStudentクラスにまとめることで、学生に関するデータと処理を整理できます。

## 11. 面接で聞かれそうな質問と回答例

### 質問1：Studentクラスを作成した理由は何ですか？

**回答例：**

学生の名前や各教科の点数を、1人分の情報としてまとめて管理するためです。Studentクラスにプロパティを用意することで、学生ごとの情報をひとまとまりに扱えるようにしました。

### 質問2：プロパティとは何ですか？

**回答例：**

オブジェクトが持つデータを取得したり設定したりするための仕組みです。今回のアプリでは、NameやMathScoreなどのプロパティを使って、学生の名前や点数を管理しています。

### 質問3：なぜ平均点の計算にdoubleを使用したのですか？

**回答例：**

平均点は小数になる可能性があるためです。整数型のintでは小数部分を扱えないので、doubleを使用しています。

### 質問4：なぜ平均点の計算をStudentクラスに書いたのですか？

**回答例：**

平均点は学生の点数に関係する処理だからです。学生情報を管理するStudentクラスに計算処理もまとめることで、関連するデータと処理を整理できると考えました。

### 質問5：Studentクラスだけで点数を0～100に制限できますか？

**回答例：**

現在の実装では、点数を0～100に制限する処理はProgramクラスのGetScoreメソッドにあります。Studentクラスは点数を保持する役割を担っています。今後は、データの不正な設定を防ぐ仕組みも検討したいです。
