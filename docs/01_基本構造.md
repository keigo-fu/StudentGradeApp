# 01. 学生成績管理アプリの基本構造

## 1. アプリケーションの概要

このアプリケーションは、C#を使用して開発した学生成績管理アプリである。

学生の名前と3科目（数学・英語・国語）の点数を登録し、登録した情報を表示・検索できる。

### 現在実装している機能

| 機能           | 内容                                     |
| -------------- | ---------------------------------------- |
| 学生情報の登録 | 名前と3科目の点数を登録する              |
| 学生情報の表示 | 登録した学生の情報と平均点を一覧表示する |
| 学生情報の検索 | 学生の名前を入力して情報を検索する       |
| 入力チェック   | 名前の未入力や0～100以外の点数を防ぐ     |
| アプリの終了   | メニューからアプリを終了する             |

※ 現在、登録した学生情報はプログラムの実行中だけ保持される。アプリを終了するとデータは失われる。

---

## 2. プログラム全体の構造

このプログラムは、大きく分けて2つのクラスで構成されている。

1. `Student` クラス
2. `Program` クラス

### 2-1. Studentクラス

```csharp
class Student
{
    public string Name { get; set; } = "";
    public int MathScore { get; set; }
    public int EnglishScore { get; set; }
    public int JapaneseScore { get; set; }

    public double GetAverage()
    {
        return (MathScore + EnglishScore + JapaneseScore) / 3.0;
    }
}
```

#### 役割

`Student` クラスは、1人の学生の情報を管理するためのクラスである。

学生の名前と各科目の点数を保持し、3科目の平均点を計算する機能を持つ。

#### 主な要素

**① プロパティ（Name、MathScoreなど）**

```csharp
public string Name { get; set; } = "";
```

- `public`：クラスの外部からアクセスできることを示す。
- `string`：文字列を扱うデータ型。
- `Name`：学生の名前を保存するプロパティ。
- `get`：保存されている値を取得する。
- `set`：新しい値を設定する。
- `= ""`：初期値として空文字を設定する。

数学・英語・国語の点数は、`int` 型で管理している。`int` は整数を扱うデータ型である。

**② GetAverageメソッド**

```csharp
public double GetAverage()
{
    return (MathScore + EnglishScore + JapaneseScore) / 3.0;
}
```

3科目の平均点を計算するメソッドである。

- `public`：クラスの外部から呼び出せる。
- `double`：小数を含む数値を扱うデータ型。
- `GetAverage()`：平均点を計算するメソッド。
- `return`：計算結果を呼び出し元に返す。

`3.0` で割っているのは、小数を含む平均点を計算するためである。

例えば、数学80点、英語70点、国語90点の場合、

(80 + 70 + 90) ÷ 3 = 80.0点

となる。

### 2-2. Programクラス

```csharp
class Program
{
    static List<Student> students = new List<Student>();

    static void Main()
    {
        // アプリのメイン処理
    }
}
```

#### 役割

`Program` クラスは、アプリケーション全体の処理を管理するクラスである。

メニューの表示、学生情報の登録、一覧表示、検索などの処理を行う。

`Student` クラスが学生1人分の情報を管理するのに対して、`Program` クラスはアプリ全体の動きを管理する。

---

## 3. Listによる学生情報の管理

```csharp
static List<Student> students = new List<Student>();
```

#### 役割

登録した複数の学生情報を管理するためのリストである。

`List<Student>` は、Student型のデータを複数保存できるコレクションである。

#### コードの意味

- `static`：クラスに属するメンバーであり、インスタンスを作らずに利用できる。
- `List<Student>`：Student型のデータを複数管理するリスト。
- `students`：リストにつけた名前。
- `new List<Student>()`：新しい空のリストを作成する。

例えば、3人の学生を登録した場合、studentsには3人分の学生情報が保存される。

#### リストへの追加

```csharp
students.Add(student);
```

`Add()` は、リストの末尾に新しい学生情報を追加するメソッドである。

#### 登録人数の確認

```csharp
students.Count
```

`Count` は、リストに登録されているデータの個数を取得するプロパティである。

## 4. Mainメソッドとアプリの実行

```csharp
static void Main()
{
    while (true)
    {
        Console.WriteLine("===== 学生成績管理アプリ =====");

        // メニュー表示と選択処理
    }
}
```

#### Mainメソッドの役割

`Main()` は、C#のコンソールアプリケーションのエントリーポイント（実行開始地点）である。

アプリケーションは基本的にMainメソッドから実行される。

#### while (true)

```csharp
while (true)
{
    // メニュー処理
}
```

`while` は、条件が成立している間、処理を繰り返す構文である。

`true` は常に真であるため、この場合はメニューを繰り返し表示する。

#### switch文

```csharp
switch (choice)
{
    case "1":
        AddStudent();
        break;

    case "2":
        ShowStudents();
        break;

    case "3":
        SearchStudent();
        break;

    case "4":
        return;

    default:
        Console.WriteLine("1～4の番号を入力してください。");
        break;
}
```

`switch` は、入力された値に応じて処理を分岐させる構文である。

| 入力   | 実行される処理             |
| ------ | -------------------------- |
| 1      | AddStudent()               |
| 2      | ShowStudents()             |
| 3      | SearchStudent()            |
| 4      | アプリを終了する           |
| その他 | エラーメッセージを表示する |

`break` は、現在のswitch文から抜けるために使用する。

一方、`return` はMainメソッド自体を終了するため、アプリケーションの終了につながる。

## 5. メソッドによる機能の分割

このアプリでは、処理ごとにメソッドを分けている。

| メソッド        | 役割                     |
| --------------- | ------------------------ |
| Main()          | メニュー表示と処理の選択 |
| AddStudent()    | 学生情報の登録           |
| GetScore()      | 点数の入力とチェック     |
| ShowStudents()  | 学生情報の一覧表示       |
| SearchStudent() | 学生情報の検索           |
| GetAverage()    | 3科目の平均点を計算      |

### メソッドに分けるメリット

1. 処理ごとの役割が明確になる。
2. 同じ処理を再利用しやすくなる。
3. コード全体を読みやすくできる。
4. 不具合が発生した場合に原因を特定しやすくなる。

例えば、点数の入力チェックをGetScore()にまとめることで、数学・英語・国語の入力時に同じ処理を利用できる。

```text

   │      ↓

   ├─ 3：学生情報を検索
   │      ↓

   │

        return
```

## 8. エンジニア面接での説明例

### Q. 今回開発したアプリについて説明してください。

C#を使用して、学生の成績を管理するコンソールアプリを開発しました。

学生の名前と数学・英語・国語の点数を登録し、登録した情報の一覧表示や名前による検索ができる仕組みです。

開発では、学生1人分の情報をStudentクラスで管理し、複数の学生情報をList<Student></student>で保存する構成にしました。

また、処理ごとにメソッドを分けることで、登録・表示・検索などの役割を整理しました。

### Q. なぜStudentクラスとProgramクラスを分けたのですか？

Studentクラスには学生の名前や点数などのデータと平均点の計算処理をまとめ、Programクラスにはアプリ全体の処理をまとめました。

このように役割を分けることで、学生情報の管理とアプリケーションの動作を区別し、コードを整理しやすくしました。

### Q. List<Student></student>を使用した理由は何ですか？

学生情報を複数人分管理する必要があったためです。

List<Student></student>を使用することで、学生情報を順番に追加したり、登録された情報を繰り返し処理で表示・検索したりできるようにしました。
