
# 05_学生情報の削除機能

## 1. 削除機能の概要

このアプリでは、登録されている学生情報を名前で検索し、該当する学生情報を削除できるようにしている。

例えば、次のような場面で削除機能を利用できる。

- 誤って登録した学生情報を削除する。
- 不要になったテストデータを削除する。
- 登録内容を整理する。

削除機能を実装することで、学生情報の登録・表示・検索・編集・削除という基本的なデータ管理機能がそろう。


## 2. なぜ削除機能を実装したのか

今回、削除機能を実装した理由は、学生情報を登録・表示・検索・編集するだけでなく、不要になった情報を適切に管理できるようにするためである。

例えば、実際の学生成績管理システムでは、次のような場面が考えられる。

- **誤登録への対応：** 学生の名前や点数を誤って登録した場合、不要なデータを削除できる。
- **重複データへの対応：** 同じ学生情報を誤って複数回登録した場合、不要な登録情報を整理できる。
- **不要なデータの整理：** 開発中に登録したテスト用データなどを削除できる。
- **データ管理の効率化：** 必要な学生情報を整理し、管理しやすい状態にできる。

また、削除機能を実装することで、データ管理における基本的な4つの操作であるCRUDを一通り学習できると考えた。

### CRUDとは何か

CRUDとは、データを管理するシステムにおける基本的な4つの操作を表す言葉である。

| 項目   | 意味             | 今回のアプリでの機能 |
| ------ | ---------------- | -------------------- |
| Create | データを作成する | 学生情報の登録       |
| Read   | データを読み取る | 学生情報の表示・検索 |
| Update | データを更新する | 学生情報の編集       |
| Delete | データを削除する | 学生情報の削除       |

今回の削除機能の実装によって、学生情報の登録から削除まで、一連のデータ管理操作を実装することができた。

### 削除機能を通じて学びたかったこと

今回の実装では、単に学生情報を削除するだけでなく、次のC#の知識を身につけることも目的とした。

1. `for` 文を使ってリスト内のデータを順番に確認する方法
2. `Count` を使ってリストの要素数を取得する方法
3. `RemoveAt()` を使って指定した位置のデータを削除する方法
4. データを確認しながらリストを変更する際の注意点
5. 削除対象が見つからない場合の処理方法

このように、削除機能はアプリの利便性を高めるだけでなく、C#のリスト操作やデータ管理の仕組みを理解するためにも重要な機能だと考えた。

### 実際のシステムで削除機能を実装する際の注意点

実際の学校の成績管理システムでは、学生情報や成績は重要なデータである。そのため、今回の学習用アプリのように、名前が一致したらすぐに削除するだけでは不十分である。

例えば、次のような仕組みが必要になる。

- 削除できるユーザーを制限する権限管理
- 削除前に対象者を確認する確認画面
- 誤削除に備えたバックアップや復元の仕組み
- 誰がいつ削除したかを記録する削除履歴

今後は、こうした安全性やデータ管理の観点も意識しながら、アプリを改善していきたい。

## 3. 削除機能のコード

今回実装した `DeleteStudent()` メソッドは、次のとおりである。

```csharp
static void DeleteStudent()
{
    Console.Write("削除する学生の名前を入力してください：");
    string name = Console.ReadLine() ?? "";

    if (string.IsNullOrWhiteSpace(name))
    {
        Console.WriteLine("名前を入力してください。");
        return;
    }

    for (int i = 0; i < students.Count; i++)
    {
        if (students[i].Name == name)
        {
            Console.WriteLine("===== 削除対象の学生 =====");
            Console.WriteLine($"名前：{students[i].Name}");
            Console.WriteLine($"数学：{students[i].MathScore}点");
            Console.WriteLine($"英語：{students[i].EnglishScore}点");
            Console.WriteLine($"国語：{students[i].JapaneseScore}点");

            students.RemoveAt(i);

            Console.WriteLine("学生情報を削除しました！");
            return;
        }
    }

    Console.WriteLine("該当する学生が見つかりませんでした。");
}
```

## 4. DeleteStudent() の処理を理解する

### ① 削除する学生の名前を入力する

```csharp
Console.Write("削除する学生の名前を入力してください：");
string name = Console.ReadLine() ?? "";
```

- `Console.Write()`：画面に入力案内を表示する。
- `Console.ReadLine()`：キーボードから入力された文字列を取得する。
- `string name`：入力された名前を格納する変数。
- `?? ""`：入力結果が `null` の場合に、空文字列を代わりに使用する。

### ② 名前が空欄でないか確認する

```csharp
if (string.IsNullOrWhiteSpace(name))
{
    Console.WriteLine("名前を入力してください。");
    return;
}
```

`string.IsNullOrWhiteSpace()` は、文字列が `null`、空文字列、または空白だけで構成されているかを確認するメソッドである。

名前が入力されていない場合は、エラーメッセージを表示して `return` で処理を終了する。

これにより、名前を入力せずに削除処理が進んでしまうことを防いでいる。

### ③ for文で学生情報を順番に確認する

```csharp
for (int i = 0; i < students.Count; i++)
```

`for` 文を使用して、学生情報を先頭から順番に確認する。

- `int i = 0`：最初の要素である0番目から確認する。
- `i < students.Count`：学生情報の件数より小さい間、繰り返す。
- `i++`：確認する位置を1つずつ進める。

`students.Count` は、リストに登録されている学生情報の件数を表す。

### ④ 入力された名前と登録済みの名前を比較する

```csharp
if (students[i].Name == name)
```

現在確認している学生の名前と、入力された名前が一致するかを比較する。

- `students[i]`：リストのi番目にある学生情報。
- `.Name`：その学生の名前。
- `==`：左右の値が等しいかを比較する演算子。

名前が一致した場合、削除対象の学生情報を表示する。

### ⑤ 削除対象の学生情報を表示する

```csharp
Console.WriteLine("===== 削除対象の学生 =====");
Console.WriteLine($"名前：{students[i].Name}");
Console.WriteLine($"数学：{students[i].MathScore}点");
Console.WriteLine($"英語：{students[i].EnglishScore}点");
Console.WriteLine($"国語：{students[i].JapaneseScore}点");
```

削除する前に、対象となる学生の名前と各教科の点数を表示している。

これにより、どの学生情報が削除されたのかを確認できる。

なお、現在の実装では表示後すぐに削除されるため、削除前の確認操作は設けていない。

### ⑥ RemoveAt() で学生情報を削除する

```csharp
students.RemoveAt(i);
```

今回の削除機能で特に重要な部分である。

`RemoveAt(i)` は、リストの指定した位置にある要素を削除するメソッドである。

例えば、次のような学生情報が登録されているとする。

| 位置 | 名前     |
| ---- | -------- |
| 0    | 山田太郎 |
| 1    | 佐藤花子 |
| 2    | 鈴木一郎 |

この状態で `students.RemoveAt(1)` を実行すると、佐藤花子の情報が削除される。

削除後は次のようになる。

| 位置 | 名前     |
| ---- | -------- |
| 0    | 山田太郎 |
| 1    | 鈴木一郎 |

削除された位置より後ろにある要素は、前に詰められる。

### ⑦ returnで処理を終了する

```csharp
Console.WriteLine("学生情報を削除しました！");
return;
```

削除が完了したことを表示し、`return` によって `DeleteStudent()` メソッドを終了する。

これにより、同じ処理の中で次の学生情報まで削除してしまうことを防いでいる。

### ⑧ 該当する学生がいなかった場合

```csharp
Console.WriteLine("該当する学生が見つかりませんでした。");
```

`for` 文でリスト内の学生情報をすべて確認しても名前が一致しなかった場合、このメッセージが表示される。

## 5. なぜforeachではなくforを使うのか

今回の削除機能では、`foreach` ではなく `for` を使用している。

`foreach` は、リストの要素を順番に取り出して確認するための繰り返し処理である。

しかし、`foreach` でリストを列挙している最中に、そのリストの要素を削除すると、コレクションが変更されたことによる例外が発生する可能性がある。

一方、`for` ではインデックス（位置）を使って要素を確認できるため、`RemoveAt(i)` によって指定位置の要素を削除できる。

今回のように、リストの要素を確認しながら削除する処理では、`for` が適している。

## 6. 削除機能の処理の流れ

1. 削除する学生の名前を入力する。
2. 名前が空欄でないか確認する。
3. `for` 文で学生情報を順番に確認する。
4. 入力された名前と登録済みの名前を比較する。
5. 名前が一致したら、削除対象の情報を表示する。
6. `RemoveAt(i)` で学生情報を削除する。
7. 削除完了のメッセージを表示する。
8. 該当する学生がいなければ、見つからなかったことを表示する。

## 9. 面接で説明できるようにする

### Q1. 削除機能はどのように実装しましたか？

学生の名前を入力してもらい、`for` 文でリスト内の学生情報を順番に確認するようにしました。名前が一致した場合は、対象となる学生の情報を表示し、`RemoveAt()` を使ってリストから削除します。削除が完了したら `return` で処理を終了する仕組みです。

### Q2. なぜforeachではなくforを使ったのですか？

今回はリストの要素を確認しながら削除する必要があったためです。`foreach` で列挙中のリストを変更すると例外が発生する可能性があります。そのため、インデックスを使って要素を確認・削除できる `for` を使用しました。

### Q3. RemoveAt()とは何ですか？

`RemoveAt()` は、リストの指定したインデックスにある要素を削除するメソッドです。今回は、名前が一致した学生の位置を指定して、その学生情報を削除しています。

### Q4. 今後、削除機能をどのように改善したいですか？

現在は名前が一致した最初の学生情報を削除する仕組みです。そのため、同姓同名の学生がいる場合には区別できません。今後は学生IDを導入して個人を識別できるようにしたいです。また、誤操作を防ぐため、削除前に確認メッセージを表示する機能も追加したいと考えています。

## 10. 今後の改善点

| 改善項目       | 内容                                             |
| -------------- | ------------------------------------------------ |
| 学生IDの導入   | 同姓同名の学生を区別できるようにする             |
| 削除前の確認   | 誤操作を防ぐため、削除するか確認する             |
| 削除履歴の保存 | いつ、どの学生情報を削除したか記録する           |
| データ保存機能 | アプリを終了しても削除結果を保持できるようにする |
