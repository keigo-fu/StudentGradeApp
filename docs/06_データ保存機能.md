
# 06. データ保存機能（JSON）

## 1. この機能を実装した目的

今回の開発では、学生情報をアプリ終了後も保持できるようにするため、JSON形式によるデータ保存機能を実装した。

これまでのアプリでは、学生情報を `List<Student>` で管理していた。しかし、この方法ではアプリを終了すると、登録した学生情報が消えてしまうという問題があった。

そこで、学生情報をJSON形式のファイルに保存し、次回起動時に読み込む仕組みを導入した。

これにより、アプリを終了・再起動しても、登録済みの学生情報を引き続き利用できるようになった。

### 今回の実装で解決した課題

- アプリを終了すると学生情報が消えてしまう。
- 登録した情報を次回起動時にも利用したい。
- 学生情報の登録・編集・削除の結果をファイルに反映したい。

## 2. JSONとは何か

JSONとは、データを保存したり、異なるプログラム間でやり取りしたりするためのデータ形式である。

JSONでは、データをキーと値の組み合わせで表現する。

例えば、今回の成績管理アプリでは、次のように学生情報を保存できる。

```json
[
  {
    "Name": "山田太郎",
    "MathScore": 80,
    "EnglishScore": 70,
    "JapaneseScore": 90
  }
]
```

この例では、学生の名前や各科目の点数が保存されている。

JSONは人間にも比較的読みやすく、C#のプログラムでも扱いやすい形式である。

## 5. SaveStudents()：学生情報を保存する機能

今回追加した保存処理は以下のとおり。

```csharp
static void SaveStudents()
{
    try
    {
        string json = JsonSerializer.Serialize(
            students,
            new JsonSerializerOptions { WriteIndented = true }
        );

        File.WriteAllText(filePath, json);

        Console.WriteLine("学生情報を保存しました！");
    }
    catch (IOException ex)
    {
        Console.WriteLine("ファイルの保存に失敗しました。");
        Console.WriteLine(ex.Message);
    }
}
```

### 重要なコードの解説

#### ① JsonSerializer.Serialize()

```csharp
string json = JsonSerializer.Serialize(
    students,
    new JsonSerializerOptions { WriteIndented = true }
);
```

`Serialize()` は、C#のオブジェクトをJSON形式の文字列に変換するメソッドである。

今回の場合、学生情報を格納している `List<Student>` をJSON形式に変換している。

`WriteIndented = true` を指定することで、JSONの内容が改行やインデントによって整形され、人間にも読みやすくなる。

#### ② File.WriteAllText()

```csharp
File.WriteAllText(filePath, json);
```

JSON形式に変換した文字列を、指定したファイルに書き込む。

今回の場合は `students.json` に学生情報を保存する。

同じファイルが存在する場合は、基本的にその内容を新しい文字列で置き換える。

#### ③ try-catch

```csharp
try
{
    // ファイルの保存処理
}
catch (IOException ex)
{
    Console.WriteLine("ファイルの保存に失敗しました。");
    Console.WriteLine(ex.Message);
}
```

ファイル操作でエラーが発生した場合に、プログラムが異常終了することを避けるための仕組みである。

`try` の中で処理を実行し、対象となる例外が発生した場合は `catch` の処理を実行する。

## 6. LoadStudents()：学生情報を読み込む機能

次に、保存した学生情報を読み込む処理を実装した。

```csharp
static void LoadStudents()
{
    if (!File.Exists(filePath))
    {
        students = new List<Student>();
        return;
    }

    try
    {
        string json = File.ReadAllText(filePath);

        students = JsonSerializer.Deserialize<List<Student>>(json)
                   ?? new List<Student>();

        Console.WriteLine($"{students.Count}件の学生情報を読み込みました！");
    }
    catch (JsonException)
    {
        Console.WriteLine("JSONファイルの形式が正しくありません。");
        students = new List<Student>();
    }
    catch (IOException ex)
    {
        Console.WriteLine("ファイルの読み込みに失敗しました。");
        Console.WriteLine(ex.Message);
        students = new List<Student>();
    }
}
```

### 重要なコードの解説

#### ① File.Exists()

```csharp
if (!File.Exists(filePath))
{
    students = new List<Student>();
    return;
}
```

保存先のファイルが存在するか確認する。

`!` は否定を表すため、ファイルが存在しない場合に中の処理を実行する。

初めてアプリを起動した場合など、まだ `students.json` が存在しない状況に対応している。

#### ② File.ReadAllText()

```csharp
string json = File.ReadAllText(filePath);
```

指定したファイルの内容を文字列として読み込む。

今回の場合は、`students.json` の内容を読み込んでいる。

#### ③ JsonSerializer.Deserialize()

```csharp
students = JsonSerializer.Deserialize<List<Student>>(json)
           ?? new List<Student>();
```

`Deserialize()` は、JSON形式の文字列をC#のオブジェクトに変換するメソッドである。

今回の場合は、JSONデータを `List<Student>` に戻している。

`??` は左側の値が `null` の場合に、右側の値を使用する演算子である。

そのため、読み込み結果が `null` だった場合には、新しい空のリストを使用する。

#### ④ JsonException

```csharp
catch (JsonException)
{
    Console.WriteLine("JSONファイルの形式が正しくありません。");
    students = new List<Student>();
}
```

JSONの形式が正しくない場合などに発生する例外を処理する。

## 7. 保存・読み込み機能を呼び出すタイミング

今回のアプリでは、学生情報が変更されたタイミングで `SaveStudents()` を呼び出すようにした。

| メソッド        | 保存処理を実行するタイミング |
| --------------- | ---------------------------- |
| AddStudent()    | 学生情報の登録後             |
| EditStudent()   | 学生情報の編集後             |
| DeleteStudent() | 学生情報の削除後             |

また、アプリ起動時には `Main()` の最初で `LoadStudents()` を実行する。

```csharp
static void Main()
{
    LoadStudents();

    while (true)
    {
        // メニューの表示と操作
    }
}
```

このようにすることで、アプリ起動時に保存済みの学生情報を読み込める。

なお、今回は登録・編集・削除のたびに保存する設計のため、終了時に改めて保存処理を実行しなくても、通常の操作による変更はすでにファイルへ反映されている。

## 8. データ保存機能の処理の流れ

```text
アプリを起動
    ↓
LoadStudents()を実行
    ↓
students.jsonは存在する？
    ├─ 存在する
    │    ↓
    │  JSONを読み込む
    │    ↓
    │  List<Student>に変換
    │
    └─ 存在しない
         ↓
       空のList<Student>を用意
    ↓
メニューを表示
    ↓
学生情報を登録・編集・削除
    ↓
SaveStudents()を実行
    ↓
JSON形式に変換
    ↓
students.jsonに保存
```

## 11. 面接で説明する場合

### 質問：今回の開発で工夫した点は何ですか？

回答例：

当初は学生情報をListで管理していたため、アプリを終了すると登録したデータが消えてしまうという課題がありました。

そこで、JSON形式で学生情報をファイルに保存する機能を実装しました。

登録・編集・削除のタイミングでデータを保存し、アプリの起動時に読み込む仕組みにしたことで、再起動後も学生情報を保持できるようにしました。

また、ファイルが存在しない場合やJSONの形式が正しくない場合などについても、例外処理を追加しました。

### 質問：なぜJSONを採用したのですか？

回答例：

今回のアプリでは、学生の名前や各科目の点数といった比較的シンプルなデータを扱っていました。

JSONはデータの構造が分かりやすく、C#の標準ライブラリであるSystem.Text.Jsonを使って扱えるため、初めてのデータ保存機能の実装に適していると考えました。

## 12. 今後の改善点

今回の実装は学習用の基本的な保存機能である。今後は次のような改善を検討したい。

| 改善項目         | 内容                                               |
| ---------------- | -------------------------------------------------- |
| データベース化   | SQLiteなどを導入してデータ管理を改善する           |
| エラー処理の強化 | 保存・読み込みに失敗した場合のデータ保護を改善する |
| 学生IDの導入     | 同姓同名の学生を区別できるようにする               |
| バックアップ     | 保存データを復元できる仕組みを追加する             |
| Webアプリ化      | ブラウザから学生情報を管理できるようにする         |

特に、JSONファイルの読み込みに失敗した場合に空のリストで処理を続けると、その後の保存操作によって元のデータを上書きする可能性がある。

実用的なアプリにする際には、読み込みに失敗した場合に処理を中断したり、元のファイルをバックアップしたりするなど、データを保護する仕組みが必要である。
