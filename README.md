# 学生成績管理アプリ（StudentGradeApp）

## 1. プロジェクト概要

C#を使用して開発した、学生の成績情報を管理するコンソールアプリケーションです。

学生の名前と各科目の点数を登録し、成績の表示・検索・編集・削除を行うことができます。また、JSON形式によるデータの保存・読み込み機能を実装し、アプリケーションを終了して再起動した後も登録した情報を保持できるようにしました。

## 2. 開発目的

C#の基礎文法やオブジェクト指向プログラミングへの理解を深めるとともに、実際に動作するアプリケーションを自分で設計・開発することを目的としています。

基本的な機能を一つずつ実装し、動作確認や修正を繰り返すことで、プログラミングの実践的な知識を身につけることを目指しました。

## 3. 実装した機能

| 機能             | 内容                                             |
| ---------------- | ------------------------------------------------ |
| 学生情報の登録   | 学生の名前と数学・英語・国語の点数を登録         |
| 学生情報の表示   | 登録した学生の成績と平均点を表示                 |
| 学生情報の検索   | 学生の名前から情報を検索                         |
| 学生情報の編集   | 登録済みの学生の成績を変更                       |
| 学生情報の削除   | 登録済みの学生情報を削除                         |
| データの保存     | JSON形式で学生情報をファイルに保存               |
| データの読み込み | アプリケーション起動時に保存済みデータを読み込み |
| 入力チェック     | 名前の未入力や0～100点以外の点数を防止           |

## 4. 使用技術

- **プログラミング言語：** C#
- **開発環境：** Visual Studio Code
- **実行環境：** .NET 10
- **データ保存形式：** JSON
- **使用ライブラリ：**
  - `System.Collections.Generic`
  - `System.IO`
  - `System.Text.Json`
- **バージョン管理：** Git / GitHub

## 6. 実行方法

.NET SDK 10.0以降がインストールされている環境で、以下のコマンドを実行してください。

```powershell
git clone https://github.com/keigo-fu/StudentGradeApp.git
cd StudentGradeApp
dotnet run
```

## 7. 工夫した点・学んだこと

### ① 機能ごとに処理を分割

学生情報の登録・表示・検索・編集・削除などの処理をメソッドに分け、コードの役割が分かりやすくなるようにしました。

### ② 入力チェックの実装

`int.TryParse()` を使用して数値として正しく入力されているか確認し、点数が0～100の範囲に収まるようにしました。また、名前の未入力を防ぐ処理も実装しました。

### ③ データの永続化

当初はアプリケーションを終了すると学生情報が失われる構成でしたが、JSON形式でファイルに保存・読み込みする機能を追加しました。

これにより、アプリケーションを再起動しても登録した学生情報を引き続き利用できるようになりました。

### ④ Git・GitHubによるバージョン管理

Gitを使用して開発履歴を管理し、GitHubにソースコードと学習用ドキュメントを公開しました。
