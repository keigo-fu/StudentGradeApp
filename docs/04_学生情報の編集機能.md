# 04_学生情報の編集機能

## 1. 編集機能の目的

この機能は、登録済みの学生を名前で検索し、数学・英語・国語の点数を変更するための機能である。

例えば、テストの成績が更新された場合などに、登録済みの学生情報を修正できる。

## 2. 編集機能の処理の流れ

1. メニューから「4. 学生情報を編集する」を選択する。
2. 編集したい学生の名前を入力する。
3. 登録済みの学生一覧から該当する学生を検索する。
4. 現在登録されている点数を表示する。
5. 新しい点数を入力する。
6. 学生情報を更新する。
7. 更新完了のメッセージを表示する。

## 3. EditStudent() メソッド

このメソッドは、学生情報の検索と点数の更新を担当する。

```csharp
static void EditStudent()
{
    Console.Write("編集する学生の名前を入力してください：");
    string name = Console.ReadLine() ?? "";

    if (string.IsNullOrWhiteSpace(name))
    {
        Console.WriteLine("名前を入力してください。");
        return;
    }

    foreach (Student student in students)
    {
        if (student.Name == name)
        {
            Console.WriteLine("===== 編集対象の学生 =====");
            Console.WriteLine($"名前：{student.Name}");
            Console.WriteLine($"数学：{student.MathScore}点");
            Console.WriteLine($"英語：{student.EnglishScore}点");
            Console.WriteLine($"国語：{student.JapaneseScore}点");

            Console.WriteLine("新しい点数を入力してください。");

            student.MathScore = GetScore("数学");
            student.EnglishScore = GetScore("英語");
            student.JapaneseScore = GetScore("国語");

            Console.WriteLine("学生情報を更新しました！");
            return;
        }
    }

    Console.WriteLine("該当する学生が見つかりませんでした。");
}
```

※実際のProgram.csと見比べ、異なる部分があれば実際のコードを優先する。

## 4. 重要なコードの解説

### ① foreachによる学生情報の検索

```csharp
foreach (Student student in students)
```

`students` に登録されている学生情報を1人ずつ取り出して確認する。

- `students`：学生情報を管理するリスト
- `Student`：学生情報を表すクラス
- `student`：現在確認している学生情報

### ② ifによる名前の照合

```csharp
if (student.Name == name)
```

登録されている学生の名前と、入力された名前が一致するかを判定する。

一致した場合、その学生の編集処理に進む。

### ③ 既存の点数を表示する

```csharp
Console.WriteLine($"数学：{student.MathScore}点");
```

現在登録されている点数を画面に表示する。

これにより、編集前の情報を確認できる。

### ④ GetScore()の再利用

```csharp
student.MathScore = GetScore("数学");
```

既存の`GetScore()`メソッドを利用して、新しい数学の点数を入力する。

このメソッドには0～100点の範囲チェックがあるため、編集時にも不正な点数が登録されないようにできる。

### ⑤ プロパティの更新

```csharp
student.MathScore = GetScore("数学");
```

入力された新しい点数を、既存の学生オブジェクトの`MathScore`プロパティに代入する。

英語と国語についても同様に更新する。

### ⑥ returnによる処理終了

```csharp
return;
```

該当する学生の編集が完了したら、メソッドの処理を終了する。

同じ名前の学生が複数登録されている場合、この実装では最初に一致した学生だけを編集する。
